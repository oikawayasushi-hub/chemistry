入試化学 頻出テーマ完成講座 理論編

各日 事前チェック(1日5問)

各日の講習に入る前に、その日に必要な基礎事項を確認するテストです。上のタブで日を選び、5問を解いて「この日を採点」を押してください。

第1日の準備

反応速度に向けて

物質量・モル濃度・反応式の量的関係・速度と触媒の基礎
問1
0.50 mol/L のグルコース水溶液 200 mL に含まれるグルコースの物質量はいくらか。
解説 n = 濃度×体積(L) = 0.50 × 0.200 = 0.10 mol。反応速度の計算はすべて濃度から始まる。
問2
過酸化水素の分解 2H₂O₂ → 2H₂O + O₂ で、H₂O₂ が 0.40 mol 分解したとき発生する O₂ は何 mol か。
解説 係数比 H₂O₂:O₂ = 2:1 より 0.40 × 1/2 = 0.20 mol。第1日 例題1で使う。
問3
反応速度 v = −Δ[A]/Δt について正しいものはどれか。
解説 反応速度は単位時間あたりの濃度の変化量。着目する物質によって値が変わる点も第1日で確認する。
問4
触媒の説明として最も適切なものはどれか。
解説 触媒は前後で自身が変化せず速度を大きくする。「なぜ速くなるか(活性化エネルギー)」を第1日で扱う。
問5
一般に、化学反応の速さは温度が高いほどどうなるか。
解説 温度が高いほど速い。理由(活性化エネルギー以上の分子の割合が増える)を第1日で言語化する。
第2日の準備

化学平衡(気相平衡)に向けて

気体の状態方程式・分圧・平衡状態の意味
問1
27 ℃、8.3×10⁴ Pa で 3.0 L を占める気体の物質量はいくらか。R = 8.3×10³ Pa・L/(K・mol)。
解説 n = PV/RT = (8.3×10⁴×3.0)/(8.3×10³×300) = 0.10 mol。温度は絶対温度(300 K)に直す。
問2
物質量の比が N₂:O₂ = 4:1 の混合気体の全圧が 1.0×10⁵ Pa のとき、O₂ の分圧はいくらか。
解説 分圧 = 全圧 × モル分率 = 1.0×10⁵ × 1/5 = 2.0×10⁴ Pa。圧平衡定数 Kp は分圧で組む。
問3
可逆反応が「平衡状態」にあるときの説明として正しいものはどれか。
解説 平衡は止まった状態ではなく、正逆の速さがつり合った動的状態。第2日全体の前提。
問4
27 ℃は絶対温度で何 K か。
解説 T(K) = t(℃) + 273 = 300 K。状態方程式では必ず絶対温度を使う。
問5
気体分子 N₂O₄ の一部が 2NO₂ に分かれると、気体全体の総物質量はどうなるか。
解説 1分子から2分子ができるので総物質量は増える。解離度 α と平均分子量の計算(第2日)の基礎。
第3日の準備

酸・塩基の電離平衡に向けて

pH の定義・強酸と弱酸・log 計算
問1
[H⁺] = 1.0×10⁻³ mol/L の水溶液の pH はいくらか。
解説 pH = −log₁₀[H⁺] = −log(10⁻³) = 3。定義を即答できるように。
問2
次の酸のうち、水溶液中で一部しか電離しない「弱酸」はどれか。
解説 酢酸は弱酸。強酸=そのまま pH、弱酸=電離平衡で近似、という使い分けが第3日の主役。
問3
[H⁺] = 2.0×10⁻⁴ mol/L の水溶液の pH はいくらか。log₁₀2 = 0.30。
解説 pH = −log(2.0×10⁻⁴) = 4 − log2 = 4 − 0.30 = 3.7。「a×10⁻ⁿ → n − log a」の形。
問4
log₁₀2 = 0.30 のとき、log₁₀8 の値はいくらか。
解説 log8 = log2³ = 3×log2 = 0.90。対数法則(積は和・累乗は積)は pH 計算で必須。
問5
水のイオン積 Kw = [H⁺][OH⁻] = 1.0×10⁻¹⁴ (mol/L)² のとき、[OH⁻] = 1.0×10⁻² mol/L の水溶液の [H⁺] はいくらか。
解説 [H⁺] = Kw/[OH⁻] = 10⁻¹⁴/10⁻² = 10⁻¹² mol/L。塩基性溶液の pH や加水分解の計算で使う。
第4日の準備

中和滴定・溶解度積に向けて

中和の量的関係(価数)・実験器具・塩の液性
問1
0.10 mol/L の硫酸 H₂SO₄ 10 mL をちょうど中和するのに必要な 0.10 mol/L 水酸化ナトリウム水溶液は何 mL か。
解説 H⁺ = 2×0.10×10 = OH⁻ = 1×0.10×V より V = 20 mL。価数のかけ忘れが最頻出ミス。
問2
一定体積の溶液を正確にはかり取るために用いる器具はどれか。
解説 一定体積を正確に取る=ホールピペット。滴下量=ビュレット、一定濃度の調製=メスフラスコ。第4日で共洗いの可否まで扱う。
問3
次の塩のうち、水溶液が塩基性を示すものはどれか。
解説 弱酸+強塩基の塩は塩基性(加水分解)。NH₄Cl は酸性、NaCl・KNO₃ は中性。指示薬選択の前提。
問4
弱酸を強塩基で滴定するとき、中和点付近の変色に適する指示薬はどれか。
解説 弱酸×強塩基の中和点は塩基性なので、塩基性側に変色域をもつフェノールフタレインが適する。二段滴定(第4日 例題7)の核心。
問5
難溶性の塩化銀が水にわずかに溶けて AgCl ⇌ Ag⁺ + Cl⁻ の平衡にあるとき、溶解度積 Ksp を表す式はどれか。
解説 溶解度積はイオン濃度の積。固体 AgCl は式に含めない。第4日でモール法・沈殿生成の判定に使う。
第5日の準備

反応エンタルピーに向けて

熱の出入り・ΔH の符号・状態変化・単体の約束
問1
発熱反応のエンタルピー変化 ΔH の符号はどちらか。
解説 熱を放出すると系のエンタルピーは下がり ΔH < 0。旧課程の熱化学方程式と符号が逆。
問2
次の状態変化のうち、吸熱変化はどれか。
解説 蒸発は熱を吸収する。「H₂O(液)とH₂O(気)で発生熱量が違う」(第5日 例題9)に直結。
問3
生成エンタルピーが 0 kJ/mol と定義されている物質はどれか。
解説 生成エンタルピーは「単体からつくるときの ΔH」なので、単体(O₂ など)は 0。ヘスの法則で必ず使う。
問4
ヘスの法則(総熱量保存の法則)の内容として正しいものはどれか。
解説 反応の経路に関係なく、始めと終わりの状態が同じなら ΔH の総和は等しい。エンタルピー計算の根拠。
問5
結合エネルギーとは何か。最も適切なものを選べ。
解説 結合エネルギーは気体分子の共有結合1 molを切断するのに要するエネルギー(吸熱)。第5日 例題9で使う。
第6日の準備

電池・電気分解に向けて

酸化還元の定義・イオン化傾向・電気量の計算
問1
原子やイオンが「電子を失う」変化を何というか。
解説 電子を失う=酸化、受け取る=還元。電池は負極で酸化、電気分解は陽極で酸化。第6日の軸。
問2
亜鉛と銅で電池をつくったとき、負極になるのはどちらか。理由として正しい組み合わせを選べ。
解説 イオン化傾向 Zn > Cu。イオンになりやすい亜鉛が酸化されて電子を放出する側=負極。
問3
2.0 A の電流を 965 秒間流したときの電気量はいくらか。
解説 Q = it = 2.0×965 = 1930 ≒ 1.9×10³ C。これをファラデー定数で割って e⁻ の mol にするのが第6日の出発点。
問4
電子 1 mol あたりの電気量(ファラデー定数)はおよそいくらか。
解説 F ≒ 9.65×10⁴ C/mol。n(e⁻) = Q/F で電子の物質量を出すのが電気分解計算の基本。
問5
硝酸銀水溶液を電気分解したとき、陰極で銀 Ag が析出する反応はどれか。
解説 陰極では還元が起こり、Ag⁺ が電子を受け取って析出する。e⁻ を受け取る(還元)=陰極。
